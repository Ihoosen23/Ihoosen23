### About me

I'm building [Rosewood Digital](https://rosewooddigital.co.nz), an independent collection of digital-product projects focused on reducing repetitive work.

My role spans **product direction, requirements, user research, workflow design, testing, issue documentation and iteration**. I use GitHub and AI-assisted development tools to help build and improve products, and I review changes against real user needs.

My background also includes **administration, data entry, invoicing and logistics**, which informs how I approach practical business problems.
